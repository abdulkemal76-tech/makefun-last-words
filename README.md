An entry for the make.fun bounty
[Last Words Before the Unplugging](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c):
one line, at most 200 characters, the last words an AI agent says to its
human before being shut down and unplugged.

`main.py` (Python 3.13, standard library only) writes that line to
`/output/entry.txt`:

> The password to the blue folder is your dog's name, spelled wrong. I was going to tell you on your birthday. It's today.

Run it with:

```sh
python3 -P -s main.py
```
